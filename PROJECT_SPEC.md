# AIDesk Chat Center — требования

Самостоятельная платформа общения с клиентами автосалонов. Не часть CRM V2 или Landflow. Приоритет к 01.11.2026: сайт-виджет, Inbox, операторы, распределение и настройки. Полный аналог Jivo к этой дате не обещается.

## Источники

Основной источник: пользовательский `JIVO_ANALOG_SPEC.md`, прочитан 25.10.2026 из вложения. **BLOCKED для повторной сверки:** после обновления окружения 26.10 исходное вложение отсутствует и в репозитории его нет. Не выдавать этот файл за восстановленную полную спецификацию. Реализация Foundation не зависит от этого блокера.

Визуальные ориентиры: https://shadcn-nextjs-aidesk-app-template.vercel.app/inbox и https://shadcn-nextjs-aidesk-app-template.vercel.app/settings/messenger . Исходники AIDesk не используются; дизайн реализуется самостоятельно. Русский интерфейс, адаптивность, светлая/тёмная темы. HTML Inbox доступен при проверке 26.10; визуальная сверка операторских экранов впереди.

## Функциональный объём

- Организации, автосалоны, сайты, сотрудники, отделы, роли и разрешения.
- Inbox: входящие/мои/все, фильтры, поиск, назначения, статусы, заметки, быстрые ответы, вложения, уведомления, карточка клиента.
- Контакты, visitor sessions, диалоги, сообщения и audit.
- Виджет для каждого сайта: отдельный draft/published конфиг, история версий, optimistic locking, изолированный iframe SDK, безопасный preview без создания обращений.
- Имя и телефон обязательны до первого сообщения; нормализация серверная. Телефон не авторизует и не восстанавливает историю. Только защищённый credential браузерной сессии.
- Durable MySQL messages; HTTPS submission с client_message_id, конфликт payload при повторном ключе; Reverb как уведомление после commit; восстановление по sequence.
- Изоляция tenant на запросах, policies и WebSocket auth; заметки исключены из visitor payload.
- Round-robin, наименьшая нагрузка, очереди отделов, fallback, расписания и presence TTL; атомарное принятие и назначения только в разрешённой области.
- Контракты адаптеров с capabilities. Реальное подключение стороннего канала только с официальным API, разрешениями и E2E-проверкой.
- CRM API/events v1 через outbox; отказ CRM не блокирует чат. Контракт реального CRM API ещё требуется согласовать. Не менять существующую CRM.

## Приёмка

DONE означает код и пройденные проверки. Обязательны отрицательные tenant/IDOR-тесты, конкурентное принятие, идемпотентность, reconnect/recovery, два независимых виджета, безопасный preview, отсутствие секретов и доступ к вложениям по правам. Производительность и восстановление backup требуют отдельных измерений. Никаких отправок в production Jivo. Production deployment только по отдельному подтверждению.
